# LAMPSTAND 2.0

### From Potential to Self-Reliance

**A refugee-led community development initiative**

Lampstand is a community-driven initiative focused on unlocking human potential, strengthening community connections, and creating opportunities for self-reliance through learning, creativity, storytelling, and dialogue.

Lampstand 2.0 is the next version of its digital platform. It aims to communicate the initiative's identity, showcase its work, document community impact, and create a credible space for collaboration and partnerships.

---

## 1. Our Vision

A community where people can recognize their potential, develop their abilities, express their creativity, and build pathways towards self-reliance.

## 2. Our Approach

Lampstand works through four complementary pillars:

### HABLOCLASS — Learning and Skills Development

A community learning initiative that promotes peer-to-peer learning, communication, English foundations, digital literacy, and coding practice.

Its approach emphasizes participation, practical exercises, and the teach-back method: learning becomes stronger when people share what they know.

### Somewhere in Africa — Photography and Visual Storytelling

A creative space for documenting African identity, culture, landscapes, everyday life, and community stories through photography and visual storytelling.

It seeks to tell meaningful stories and create opportunities for people to see their communities from new perspectives.

### Tea Table — Dialogue and Human Connection

A space for reflection, listening, meaningful conversations, and shared experiences.

It values human connection and creates opportunities for people to exchange ideas, learn from one another, and strengthen community relationships.

### Arts & Design — Creativity and Expression

A platform for artistic expression, visual communication, design exploration, and creative development.

It encourages people to discover their talents, develop creative skills, and communicate ideas through art and design.

---

## 3. Project Objectives

Lampstand 2.0 aims to:

- Present Lampstand's vision, mission, and four pillars.
- Showcase real activities, projects, and community experiences.
- Document progress and make achievements visible.
- Provide a photographic gallery for each pillar.
- Communicate opportunities for participation and collaboration.
- Build trust through transparent and credible information.
- Establish a foundation for future digital development.

## 5. Main Website Structure

The website is organized around the following sections:

- **Home:** Introduction to Lampstand, vision, mission, and four pillars.
- **About:** Background, identity, values, and approach.
- **Our Pillars:** Dedicated pages for each of the four initiatives.
- **Our Impact:** Activities, documented progress, stories, and outcomes.
- **Gallery:** Photographic documentation of community activities.
- **Get Involved:** Opportunities to participate, collaborate, or support.
- **Contact:** Communication and partnership enquiries.

## 6. Photography and Impact Galleries

Each pillar will have its own photographic gallery to make its activities and identity more visible.

The galleries should include:

- Horizontal scrolling and touch-friendly navigation.
- Previous and next controls.
- Image captions and brief descriptions.
- A larger image viewing experience.
- Responsive layouts for mobile, tablet, and desktop.
- Lazy loading for better performance.

Photography should prioritize authentic Lampstand activities and community experiences. Images from other sources must not be presented as evidence of Lampstand's work.

Identifiable participants should be photographed and featured with appropriate consent.

## 7. Design Philosophy

Lampstand 2.0 should communicate credibility, creativity, humanity, and community ownership.

The design will follow these principles:

- Clear and accessible navigation.
- Responsive layouts across devices.
- Strong typography and meaningful visual hierarchy.
- Authentic photography and storytelling.
- Consistent design across all four pillars.
- Distinct visual identities for individual pillars.
- Subtle animations that support, rather than distract from, content.
- Accessible colour contrast and readable text.

## 8. Getting Started

### Prerequisites

Install Node.js and npm before starting.

### Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Enter the project directory:

```bash
cd lampstand-2
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## 9. Development Principles

Development should follow a structured process:

1. Establish the global design system.
2. Build the navigation and homepage.
3. Develop the four pillar pages.
4. Create reusable photographic gallery components.
5. Add animations and responsive interactions.
6. Integrate authentic project content and documentation.
7. Test accessibility, responsiveness, and performance.
8. Prepare the website for deployment.

Components should be reusable, code should remain organized, and changes should preserve the consistency of the overall design.

## 10. Project Boundaries

Lampstand is a community-led initiative, not an official UNHCR platform or representative.

HABARI is a separate refugee information platform and is not one of Lampstand's four pillars.

All public claims, achievements, partnerships, statistics, and impact statements must be supported by verifiable information.
